# Release Notes

## AOAI Chat AI 1.2.1 (2026-05-09)

### Key Improvements
* **Open-Source Infrastructure**: Significant improvements to the project structure and documentation for open-source readiness.
* **Distributed AI Sessions**: Enhanced handling of `AOAISessionService` for more stable distributed AI background tasks.
* **Privacy & Permissions**: Improved management of system permissions, including the removal of unnecessary `READ_PHONE_STATE` for better user privacy.
* **Security & Cleanup**: Hardened security by optimizing Git history and removing sensitive credentials from the repository.
* **Community Contribution**: Added infrastructure for community involvement, including Issue Templates and a Code of Conduct.
* **Performance**: General stability and performance improvements across the core AI logic and UI.
