# Security Policy

## Supported Versions

Only the latest version of AOAI is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

## Reporting a Vulnerability

We take the security of AOAI seriously. If you find a security vulnerability, please do not disclose it publicly. Instead, please report it via one of the following methods:

1. **GitHub Issues**: Open a private issue if possible (if the repo supports it).
2. **Email**: [Add security contact email here]

We will acknowledge your report within 48 hours and provide a timeline for a fix.
